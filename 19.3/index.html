FIELD NOTES / machine learning MURPHY · §19.3 CONTEXT

SUPERVISED · UNSUPERVISED · SEMI-SUPERVISED

Who gives
the answers?

The three kinds of learning differ in one thing: how many of your examples come with the right answer (a label) attached.

  • Supervised Every example is labeled. Learn to predict the label.
  • Unsupervised No labels at all. Find structure: groups, oddities, simpler descriptions.
  • Semi-supervised A few labels and a lot of unlabeled data. Use the unlabeled data to make the few labels go further. (This is §19.3.)

This page fills in the middle row, unsupervised learning, and then sets all three side by side. Every chart runs in your browser on small synthetic datasets modeled on real problems.

1 · THE LABEL QUESTION

Labels are the expensive part

Collecting raw data is usually cheap: cameras, logs and web crawlers produce it nonstop. Getting someone to write the right answer next to each example is slow and costs money, and sometimes it needs an expert. A radiologist has to read the scan, a linguist has to transcribe the recording, a lab has to run the assay.

So the practical question in most projects is how many labels can we afford, and what do we do with everything else?

SUPERVISED

Learn from an answer key

(x, y) pairs: input and the correct output

The model sees thousands of examples like “this email → spam” and learns a function that maps inputs to outputs. It can be classification (pick a category) or regression (predict a number).

Everyday analogy: studying with worked solutions.

UNSUPERVISED

Find structure without answers

x only: inputs, no outputs

There is nothing to predict, so the model looks for patterns in the inputs: clusters of similar items, anomalies that don’t fit, or a smaller set of directions that captures most of the variation.

Everyday analogy: sorting a drawer of unlabeled photos into piles.

SEMI-SUPERVISED

A few answers plus lots of data

A few (x, y) pairs plus many x alone

The goal is still to predict y, as in supervised learning. The unlabeled examples show how the data is shaped, and that tells the model where a decision boundary can and can’t sensibly go.

Everyday analogy: a teacher grades three essays; you infer the rubric by reading the whole pile.

What to try

  • At 2–6 labels, supervised draws a boundary that cuts through both arcs. Semi-supervised usually gets nearly everything right, because the unlabeled dots outline the arcs.
  • At 300 labels, supervised catches up. When labels are plentiful, the unlabeled data has little left to add.
  • The unsupervised panel never changes, and it splits the data left/right, not by arc. It finds a structure (two compact blobs), not necessarily the structure you care about. This is the main risk of unsupervised learning.
  • Semi-supervised works here because the classes follow the shape of the data (the cluster or manifold assumption in §19.3). Where that assumption fails, unlabeled data can mislead the model.
3 · THE UNSUPERVISED TOOLKIT

Three jobs you can do with no labels

Unsupervised learning isn't a single algorithm. It is a family of tools that each answer a different question about unlabeled data. The three below are the ones you'll meet most often in practice.

“Are there natural groups in this data?”

More clusters always reduce the distance, so the smallest number doesn't tell you the right k. Look for the bend where adding clusters stops helping much.

WHAT THE ALGORITHM FOUND

The algorithm only outputs numbers. Names like “weekly big shop” come from a person who looks at the centers, so interpretation stays a human job.

USED FOR
  • Customer segmentation: tailor offers to groups nobody defined in advance.
  • Grouping news stories: put 40 articles about the same event under one headline.
  • Cell types in biology: cluster single-cell gene measurements to find new cell types.
  • Image compression: replace millions of colors with the k most representative ones.

“Which of these doesn't look like the others?”

NEAREST-NEIGHBOR DISTANCE

Flagging odd card transactions

USED FOR
  • Fraud and intrusion detection: new attack patterns have no labels yet, but they still look unusual.
  • Manufacturing: spot defective parts when almost every training example is fine.
  • Equipment monitoring: warn when a turbine's vibration pattern drifts from normal.
  • Data cleaning: find sensor glitches and typos before training any other model.

“Can I describe this data with fewer numbers?”

PCA

Squashing two exam scores into one

SPREAD KEPT BY THIS ONE NUMBER

PCA picks the direction where the projected points are most spread out, because that direction keeps the most information. Here it amounts to an “overall ability” score.

Real datasets have hundreds or thousands of columns. PCA and its nonlinear relatives (t-SNE, UMAP, autoencoders) reduce them to a few, which you can plot or feed to another model.

USED FOR
  • Visualization: plot 20,000-gene or 768-dimensional embedding data on a 2-D screen.
  • Compression and denoising: keep the main directions, drop the noise.
  • Preprocessing: give a supervised model 10 informative features instead of 1,000 redundant ones.
  • Survey analysis: summarize 50 questionnaire items as a few underlying traits.

Also unsupervised: density estimation (how likely is this x?), topic models (what themes run through these documents?), and generative models such as VAEs and diffusion models, which learn the data distribution well enough to produce new samples. §19.3 uses some of these (e.g. VAEs) as building blocks for semi-supervised learning.

5 · PROS & CONS

What each approach costs you

SUPERVISED
  • Clear goal, easy to evaluate: accuracy on held-out labeled data.
  • Usually the most accurate option once you have enough labels.
  • Mature, well-understood tools (linear models, trees, neural nets).
  • Labels are slow and expensive, and often need experts.
  • The model learns whatever the labels say, including their mistakes and biases.
  • Can't find categories nobody labeled, e.g. a brand-new fraud type.
UNSUPERVISED
  • Needs no labels, so it can use huge amounts of raw data.
  • Can find structure you didn't know to look for: new segments, new anomalies.
  • Useful for exploring data, compressing it, and building features for other models.
  • No answer key, so it's hard to say whether a result is “right”. Choices like k are partly judgment calls.
  • The structure it finds may not match your goal (the left/right split in §2).
  • Results depend heavily on feature scaling and the distance measure, and a person has to interpret them.
SEMI-SUPERVISED
  • Makes a small label budget go much further by using cheap unlabeled data.
  • Often comes close to fully supervised accuracy with a fraction of the labels.
  • Fits a very common real situation: a little labeled data and a lot of raw data.
  • Depends on assumptions (classes follow clusters or the data's shape). If they're wrong, it can do worse than supervised.
  • Self-training can reinforce its own mistakes (confirmation bias in pseudo-labels).
  • More moving parts and hyperparameters, and tuning them is hard with only a small labeled validation set.

Two relatives worth knowing

  • Self-supervised learning generates labels from the data itself, for example by hiding a word and predicting it, or predicting the next frame of a video. This is how large language models are pre-trained. It's often grouped with unsupervised learning, and §19.3 shows how it can be combined with semi-supervised learning: pre-train on unlabeled data, then fine-tune on the few labels.
  • Reinforcement learning has no labels either, but it gets a reward after acting (win/lose, profit, user click). It's the right tool when your decisions affect what data you see next, as in games, robotics or recommendation.
7 · SELF-CHECK

Test yourself

k-means returns clusters 0, 1, 2. Why can't you report its “accuracy” straight away?

Because there's no answer key. The cluster numbers are arbitrary, and nothing guarantees they correspond to any category you care about. You would need labels (from a person) to name clusters and then measure agreement, which is exactly what §2 does with “accuracy if someone names the clusters”.

In §2, why does semi-supervised beat supervised with 4 labels but not with 300?

With 4 labels the supervised model has almost nothing to go on, so its boundary is close to arbitrary. The unlabeled points show where the arcs are, and label propagation follows them. With 300 labels the supervised model already sees the arcs through its own labeled points, so the unlabeled data adds little.

When could adding unlabeled data make a model worse?

When the classes don't follow the data's structure, for example if two classes overlap in one dense blob, or one natural cluster contains both classes. Methods that push boundaries into low-density gaps, or spread labels along neighbors, will then confidently put the boundary in the wrong place. Self-training can also amplify early mistakes.

A bank has millions of transactions, only a few hundred confirmed frauds, and fraudsters keep changing tactics. Which approaches would you combine?

Unsupervised anomaly detection to catch new, unlabeled patterns; supervised (or semi-supervised) classification on the confirmed cases to catch known patterns precisely; and analysts' reviews of flagged items as new labels that feed back into the system.

Is PCA supervised or unsupervised? What about using PCA features inside a classifier?

PCA itself is unsupervised: it uses only x. Using its outputs as inputs to a classifier makes a two-stage pipeline, unsupervised feature learning followed by supervised prediction. Many semi-supervised methods follow the same pattern: learn representations from unlabeled data, then train on the labels.
